# Changelog

All notable changes to this project are documented here.
The format follows [Keep a Changelog](https://keepachangelog.com/en/1.1.0/), and this project uses
[Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [1.4.0] — 2026-09-24

### Added

- **A toggle for every biome.** The config screen has a second page with an on/off switch per biome
  (seven per page, plus **Enable all** / **Disable all** and **Back**). Turn a biome off and parrots
  no longer spawn there: the natural spawn entry skips it and the flock spawner refuses it, so birds
  can be kept out of oceans, deserts, or anywhere else. The list covers every biome the loaded world
  knows about, including datapack and modded ones; the vanilla list is shown at the main menu, before
  a world is loaded.
- `/birds check` now reports whether spawning is enabled in the biome you are standing in.

### Changed

- Mod Menu is resolved from the Modrinth maven instead of a jar kept in the repository.

## [1.3.0] — 2026-09-23

Initial release.

### Added

- **Parrots spawn in every biome.** A parrot spawn entry is added to every biome that does not
  already have one (63 of 66 biomes), with jungles left to vanilla's own entry.
- **Relaxed spawn surface.** Vanilla's "grass, leaves or logs only" check is replaced with "a solid
  block below, an empty spawn position, no fluid, and light > 8 in the Overworld". Oceans, rivers and
  mid-air stay empty, because water and air are not floors. The light rule is skipped in the Nether
  and the End.
- **Six biome skins.** `vanilla`, `arid` (desert, badlands, savanna), `snowy` (snowy and frozen
  biomes), `mushroom` (mushroom fields), `nether` (all Nether biomes) and `end` (all End biomes).
  The skin is rolled once from the biome the parrot spawns in, saved with the entity, and synced to
  clients.
- **Shoulder parrots keep their skin**, on every client: the skin is carried on the player alongside
  vanilla's parrot variant and used by the shoulder layer.
- **Independent flock spawner.** Vanilla's passive spawner is throttled to one attempt every 400 ticks
  and gated by a creature cap that world-generation animals have already filled, so a spawn entry
  alone changes nothing in an explored world. The mod additionally places small flocks 32–56 blocks
  from players on an interval, using exactly the same spawn rules, and caps how many parrots may
  accumulate nearby.
- **Config file** `config/birds-in-every-biome.json` (spawn weight, group sizes, jungle skipping,
  flock on/off, flock interval, nearby cap), with clamping on load and automatic migration of
  legacy config file names.
- **Mod Menu config screen** — sliders, toggles, Save / Cancel / Restore defaults. Built from vanilla
  widgets, so Cloth Config is not required.
- **`/birds check` and `/birds spawn`** diagnostics, including the reason a position was rejected and
  the outcome of a forced flock attempt.
- **Documentation**: `README.md`, `docs/TECHNICAL.md` (architecture and extension guide),
  `docs/TEXTURES.md` (32×32 parrot texture spec and generator workflow).

### Notes

- Requires Minecraft 26.2, Fabric Loader 0.19.5+, Fabric API and Java 25.
- The bundled biome variants are recolours of Mojang's parrot texture, generated by
  `tools/make_textures.py`. See the asset note in `docs/TEXTURES.md`.
