Minecraft 26.3 support.

**Rebuilt for Minecraft 26.3** — same mod, on Fabric Loader 0.19.5 and Fabric API 0.161.0+26.3.
Nothing about how it plays changed: same features, same config file and the same data format, so
existing worlds, settings and birds carry over untouched.

**New biome: dappled forest** - Minecraft 26.3's `minecraft:dappled_forest` biome is in the config
screen's biome list, so it can be toggled like every other biome. Birds there use the vanilla
plumage, like the other forests; unknown biomes were already allowed by default.
