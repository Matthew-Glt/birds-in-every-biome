Biome toggles.

**A switch for every biome** - the config screen has a second page, **Biome toggles**, with an on/off
switch per biome (seven per page, plus **Enable all** / **Disable all** and **Back**). Turning a biome
off stops parrots spawning there: the natural spawn entry skips it and the flock spawner refuses it,
so birds stay out of oceans, deserts, or wherever you prefer. Every biome the loaded world knows about
is listed, including datapack and modded ones; the vanilla list is used at the main menu, before a
world is loaded. In the config file this is the `disabledBiomes` array - unknown ids are allowed, so
biomes added by future updates stay on by default.

**Diagnostics** - `/birds check` now prints whether spawning is enabled in the biome you are standing
in, so a toggle can be confirmed without hunting for birds.

Changes apply the next time the world loads, since biome spawn lists are built at world load.
