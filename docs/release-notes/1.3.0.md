Initial release.

**Parrots in every biome** — a parrot spawn entry is added to every biome that doesn't already have
one (63 of 66; jungles keep vanilla's own entry). Vanilla's "grass, leaves or logs only" spawn surface
is replaced with "a solid block below, an empty spawn position, no fluid, and light > 8 in the
Overworld" — the light rule is skipped in the Nether and the End. Oceans, rivers and mid-air stay
empty, because water and air are not floors.

**Six biome skins** — `arid` (desert, badlands, savanna), `snowy` (snowy and frozen biomes),
`mushroom` (mushroom fields), `nether` (all Nether biomes) and `end` (all End biomes), with vanilla
parrots everywhere else. The skin is rolled once from the biome the parrot spawns in, saved with the
entity and synced to clients, so a bird keeps its look wherever it wanders. Shoulder parrots keep it
too, on every client.

**Flocks, so you actually see birds** — vanilla's passive spawner only tries once every 400 ticks and
is gated by a creature cap that world-generation animals have already filled, so a spawn entry alone
changes nothing in an explored world. The mod places small flocks 32-56 blocks from each player on an
interval, using exactly the same spawn rules, capped by how many parrots are already nearby.

**Config and diagnostics** — `config/birds-in-every-biome.json` (spawn weight, group sizes, jungle
skipping, flocks on/off, flock interval, nearby cap) with clamping on load, plus a Mod Menu config
screen built from vanilla widgets. `/birds check` explains why a position would or wouldn't spawn a
bird, and `/birds spawn` forces one flock attempt and reports the outcome.

**Documentation** — full write-up in the README, architecture and extension guide in
`docs/TECHNICAL.md`, and the 32x32 parrot texture spec with the generator workflow in
`docs/TEXTURES.md`.

Requires Minecraft 26.2, Fabric Loader 0.19.5+, Fabric API and Java 25.
